Gmail koppelen

Eenmalige setup via Google Cloud. Je geeft de app alleen leestoegang — er wordt niets verstuurd of gewijzigd.

1
Ga naar console.cloud.google.com en maak een project aan (bijv. "Dagplanner")
2
Ga naar APIs & Services → Library, zoek "Gmail API" én "Google Calendar API" en zet beide aan
3
Ga naar OAuth consent screen → External → vul naam + e-mail in → sla op
4
Ga naar Credentials → Create Credentials → OAuth 2.0 Client ID → kies Web application
5
Voeg bij Authorized JavaScript origins toe (klik om te kopiëren):
6
Je hoeft geen redirect URI in te vullen — dat is niet nodig met de nieuwe login-methode
7
Kopieer je Client ID en plak het hieronder

Anthropic API-sleutel

Voor het automatisch opsplitsen van projecten gebruik ik de Claude API. Je sleutel wordt alleen lokaal opgeslagen in je browser.

Haal gratis een sleutel op via console.anthropic.com → API Keys → Create Key.
