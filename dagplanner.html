Gmail koppelen

Eenmalige setup via Google Cloud (~10 min). Je geeft de app alleen leestoegang tot je inbox — er wordt niets verstuurd of gewijzigd.

1
Ga naar console.cloud.google.com en maak een nieuw project aan (bijv. "Dagplanner")
2
Ga naar APIs & Services → Library, zoek op "Gmail API" en zet hem aan
3
Ga naar OAuth consent screen → kies "External" → vul je naam en e-mail in → sla op
4
Ga naar Credentials → Create Credentials → OAuth 2.0 Client ID → kies type Web application
5
Voeg bij Authorized JavaScript origins het volgende toe (klik om te kopiëren):
6
Kopieer je Client ID en plak het hieronder
